Library Management System  :- 

A full‑stack application built with React (frontend) and Spring Boot (backend) to manage books, users, and assignments in a digital library.

🔑 Features :-

User Management → Register, login, update, and delete users with role‑based access (Admin/User).

Book Management → Add, update, view, and delete books.

Assignment System → Admins can assign books to users, track issue/return dates, and update status.

Role-Based Access → Protected routes for Admin and User dashboards.

User Dashboard → Users can view borrowed books, check status, and manage their profile.

Admin Dashboard → Admins can manage books, users, and assignments.

🛠️ Tech Stack :-

Frontend: React, TailwindCSS, Axios, React Router

Backend: Spring Boot, REST APIs

Database: MySQL (JPA/Hibernate)

🚀 How to Run
Clone the repo.

Start backend (Spring Boot) → mvn spring-boot:run.

Start frontend (React) → npm run dev.

Access app at http://localhost:5173.
